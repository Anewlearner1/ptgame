# 復健科診所物語

經營一間台灣的復健科診所。從一間小小的診間開始，決定要做健保、還是走自費路線，
安排物理治療、職能與語言治療的動線，在健保與自費之間找到自己的平衡點。

畫面是 2.5D 等角視角的像素風格（致敬 Kairosoft 系列經營遊戲），全部以網頁技術製作，
不需要安裝任何東西。

## 遊玩方式

### 在本機執行

本遊戲是純靜態網站，需要透過靜態伺服器開啟（直接雙擊 `index.html` 因瀏覽器對
ES module 的限制無法載入）。在專案資料夾執行：

```bash
python3 -m http.server 8000
```

然後用瀏覽器開啟 <http://localhost:8000/>。

### 線上遊玩（GitHub Pages）

線上試玩：<https://anewlearner1.github.io/ptgame/>

所有資源都使用相對路徑。本專案已附自動部署 workflow（`.github/workflows/pages.yml`），推送到 `main` 或 `claude/rehab-clinic-game` 就會自動發布。第一次使用需要：

1. 到 **Settings → Pages**，Source 選 **GitHub Actions**。
2. 到 **Settings → Environments → github-pages**，把要部署的分支加入允許清單。

## 操作方式

| 操作 | 功能 |
|---|---|
| 左鍵點擊 | 建造（依目前選取的工具放置設施、拖曳鋪地板、拆除，或選取病患／員工／設施查看資料） |
| `Shift` + 左鍵 | 連續放置同一種設施（沒按 Shift 的話，放好一個就會取消工具） |
| 右鍵拖曳（或中鍵拖曳） | 平移視角；在建造中單擊右鍵＝取消工具 |
| 滾輪 | 縮放（0.5～2.5 倍） |
| `R`（或 `Alt` + 滾輪） | 旋轉待放置（或搬移中）的設施 |
| `M` | 移動工具：點設備拿起（搬移費＝造價 10%，最少 NT$ 500；原地轉向免費），點空位放下；`Esc`／右鍵取消。手機：長按設備 → 「移動」，拖曳 ✔ 確認 |
| `Esc` | 取消目前工具、關閉面板 |
| `G` | 顯示／隱藏格線 |
| `Space` | 暫停／繼續 |
| `1` / `2` / `3` | 速度 ×1 / ×2 / ×3 |
| `B` `O` `C` `V` `P` `Y` | 開啟 建造／運作／診所／一覽／地圖／系統 面板 |
| `?` 或 `F1` | 操作說明 |

右下角也有速度按鈕與「跳過本週」。觸控裝置可以用雙指平移。

## 系統設定：效能診斷、畫質、幀率上限、效能報告

手機卡頓或發熱時，到「系統 → 設定」：

| 項目 | 說明 |
|---|---|
| **效能診斷** | 打開後畫面左上角會顯示 fps（平均與 1% 最低）、每幀耗時（p50／p95）、模擬／繪製／介面各花幾 ms、場上角色數、畫布實際像素、DPR、畫質等級、美術風格、診所等級與 JS 記憶體。也可以用網址 `?perf=1` 開啟，電腦按 `F3` 切換。 |
| **畫質** | 自動（手機依幀率自動降級，電腦維持最高）／高／中（解析度上限 2 倍、關閉車輛與天氣粒子、行走不搖擺）／低（解析度上限約 1.25 倍、無地面陰影）。立即生效並記在這台裝置。 |
| **幀率上限** | 60（預設）或 30。30 會隔一次才繪製，省電、少發熱；遊戲時間仍依真實秒數前進，速度不變。 |
| **📋 效能報告** | 自動跑 12 秒測試：把速度固定成 ×3，先量目前縮放，再量放大 ×1.6，期間請勿操作（可按「取消」或 `Esc`），結束後自動還原速度與視角。 |
| **關於 → 版本** | 顯示這份遊戲的建置版本（部署時產生的 `version.json`；本機開發顯示 `dev`）。網頁開著時若有新版本上線，會跳出「有新版本，重新整理即可更新」。 |

### 把效能報告貼回給開發者

1. 先照平常的玩法玩一陣子，讓診所有一些病患與設備（角色越多數字越有參考價值）。
2. 系統 → 設定 → 「📋 效能報告」，等 12 秒。
3. 跳出報告視窗後按「複製」（或「分享」），把整段文字貼回來即可。內容包含版本、瀏覽器與裝置資訊、GPU 型號、畫質／幀率設定，以及兩個縮放下的 fps、1% 低、幀時間、模擬／繪製／介面耗時。
4. 想比較畫質，可在「畫質」切到 低／中／高 各跑一次。

## 遊戲循環

### 時間

- 一週等於一個營業日，診所每天 08:00 至 20:00 營業（速度 ×1 時約 45 秒真實時間）。
- 4 週為一個月，12 個月為一年。
- 每月底結算：發薪水、付租金與設施維護費，並結算健保收入。
- 遊戲每月底自動存檔；有重大決定（隨機事件、醫病溝通兩難）彈出時，時間會暫停直到你做出選擇。

### 資金

- 起始資金 NT$ 110 萬（NT$ 120 萬扣掉開業時已經蓋好的掛號櫃檯、看診室、兩台熱敷箱、電療儀、沙發與綠植的部分費用），並請了醫師、護理師、物理治療師各一名。
- 拆除設施退回 50% 建造費；員工人數有診所等級的上限。
- 月底資金低於 NT$ -300,000 即宣告破產，遊戲結束。

### 健保與自費（真實費率）

費率資料集中在 `js/data/fees.js`（調查日期 2026-10；來自搜尋結果摘要，附可信度標示，低可信度的數字尚待對照健保署支付標準）。

- **健保**：治療會累積健保點數，月底才依「點值」換算成收入。點值預設 **0.95**（西醫基層實際行情）；
  超過診所等級的月點數上限（巷弄小診所 28,000 點、社區 38,000、地區 56,000、頂尖 82,000）後，
  點值會按「上限 ÷ 申報點數」下降，最低 0.6，所有點數一起打折。一直堆便宜的電熱療，收入很快就會停滯，年底的健保署抽查也會扣分。
- **同日物理治療僅給付最高一項**：熱敷、電療、牽引、紅外線、貼紮、健保徒手同一次就診只申報最高階（簡單 95／中度 200 點）一次，
  其餘照做、照樣累積研發點數，但不另計點；職能（感統、精細動作）、語言治療、超音波與診察費各自申報。
- **診察費依當日看診人數遞減**：前 35 人 364 點，36–45 人 250 點，46–65 人 200 點（估計），66 人以上 160 點。人多的日子診察費會被稀釋。
- **部分負擔**：回診（第 2 次起）每次 NT$ 50，直接進帳。
- **自費**：治療當下即時收取現金，價格是真實的每次行情（震波 2,500、高能雷射 2,000、自費徒手 2,000、懸吊 1,700、PRP 17,000、鞋墊 5,000）。
  在「運作 → 自費定價」可以把價格調到市場典型價的 0.5～2.0 倍（旁邊列出市場行情低–高），定價越高，病患越不願意加購、滿意度也越低。
  只有少數病患（約一成多）願意加購，且需要先研發、蓋好昂貴的專用診間。
- **每位模擬病患代表 15 位真實病患**（`economy.PATIENT_WEIGHT`）：健保給付、自費與部分負擔都乘上這個權重後入帳；
  最大的「全台頂尖」診所（20×16）因同時在場病患上限提高到 100 人，權重改為每位代表 20 位真實病患；
  薪水、房租、造價與事件金額則是實際金額。月底營運報告分列「健保給付／自費收入／部分負擔」。
- 研發自費項目（PRP 增生療法、體外震波、高能量雷射、客製化鞋墊、自費徒手、懸吊運動）
  並提高自費轉換率，是擺脫點數稀釋、提高單人收入的主要方法。

### 專區組合

把特定設施相鄰擺放，會啟動「專區」並提供加成。相鄰指兩個設施的範圍彼此接觸（含斜角）；
一整群相連的設施只要包含專區所需的全部種類即可，地板不算。同一專區蓋多個不會重複加成。

- **黃金三寶區**：熱敷、電療、牽引相鄰擺放，健保治療的翻桌率 +20%，長輩滿意度 +8。
- **高階自費專區**：徒手治療室、體外震波、咖啡機相鄰擺放，自費轉換率 +15%、自費單價 +10%。
- **早療放電樂園**：球池、防撞軟墊、繪本架相鄰擺放，研發點數獲得量 ×1.25。
- **候診舒適區**：沙發、飲水機、綠植、電視牆相鄰，病患耐心 +10%、長輩滿意度 +2。
- **員工喘息站**：休息室旁設飲水機，員工體力消耗 -10%。

可在「一覽 → 專區組合辭典」查看所有專區的需求與目前是否啟動。

### 研發點數

每完成一次療程，會產生三種研發點數：**醫術、儀器、服務**（技術好的員工、早療樂園專區都會增加產出）。
在「運作 → 研發」花費對應的點數，一次研發一項，需要數週完成：

- **醫術**：超音波、PRP、徒手、職能／語言治療、運動傷害與長者照護等，解鎖診療項目與客群。
- **儀器**：熱敷效率、震波、雷射、懸吊、鞋墊、步態分析，解鎖設備與自費療程。
- **服務**：掛號數位化、行政流程（病患走路更快）、衛教話術（自費轉換率）、社區口碑（聲譽）、
  人力排班與「擴建規劃」（員工名額；第 3、4 級診所的擴建都要先完成它）。

員工訓練（提升技術）也會消耗服務點數與金錢。

### 病患與員工

- 四種客群：晨間長輩團、肩頸僵硬上班族、運動傷害病患、早療兒童與家長；各自有不同的來診時段、耐心、自費意願與療程組合。
- 病患會依季節、天氣與社區活動進場，依序經過掛號、候診、治療與結帳。
- 病患的滿意度會影響診所聲譽，聲譽又會影響之後的病患數量。
- 員工（醫師、物理治療師、職能治療師、語言治療師、櫃檯護理師）各有**技術**（影響療程速度、點數與療效）、
  **親和力**（影響自費轉換與聊天滿意度）與**體力**（工作會消耗，太累會變慢，需要休息室或閒置時恢復）。

### 在地事件

- **天氣**：寒流（12～2 月）長輩暴增；午後雷陣雨與梅雨容易滑倒，鋪**防滑地墊**或坡道就能大幅減少；
  炎夏人少又耗體力；颱風天病人大減。
- **社區活動**（運作 → 社區衛教）：宮廟肌少症篩檢、校園脊椎側彎篩檢、里民健走、長照據點合作等，花錢換取一段時間的客群與聲譽加成，有冷卻時間。
- **衛教看板**與**經營方針**（骨科／長照／早療）：調整各客群的來診比例。
- **醫病溝通兩難**：病患要求「直接開止痛藥」、「只做電療不要看醫生」、一次買十堂療程……每個選擇都影響聲譽、滿意度或健保點數。
- **隨機事件**：里長邀約、健保署抽審、媒體採訪、員工被挖角、廠商促銷、颱風淹水等。

### 評鑑與擴建

- 每年年底衛生局督導與健保署抽查：檢查無障礙坡道、候診座位、防滑地面、執照人員（沒有醫師或物理治療師直接不合格）、
  病患滿意度與健保申報是否過度。通過可得聲譽（高分另有獎勵金），不通過則罰款並扣聲譽。
- 診所分四級：巷弄小診所（12×10）→ 社區診所（14×12）→ 地區復健中心（16×14）→ 全台頂尖復健中心（20×16）。
  升級需要足夠的聲譽、年資、員工數、滿意度、無障礙坡道、候診座位與擴建費用，在「診所 → 擴建」查看條件。
  擴建後原有的設施與地板位置不變，只是可建範圍變大。
- 遊戲提供三個存檔欄位與自動存檔，並可匯出、匯入 JSON。

## 開發注意事項

- 本專案不使用任何建置工具，也沒有 npm 執行期相依套件，不使用外部字型或 CDN 資源。
- 所有使用者可見的文字皆為繁體中文（台灣用語）。
- 修改程式碼後，可用 `node --check <檔案>` 先檢查語法。
- 系統稽核：`node tools/audit.mjs`（Node 無頭執行，約數分鐘；加 `--quick` 較快）會檢查 PRD 功能、五年長跑的數值完整性、存檔／讀檔一致性與邊界情況。
  瀏覽器回歸測試：先 `python3 -m http.server 8201`，再 `node tools/play.mjs`、`node tools/smoke.mjs`。
- 效能診斷測試：先 `python3 -m http.server 8213`，再 `node tools/perftest.mjs`（加 `--quick` 略過兩次 12 秒的實測）。
- 部署時 `.github/workflows/pages.yml` 會寫入 `_site/version.json`（`{"sha","built"}`）。本機沒有這個檔案，版本顯示 `dev`，也不會檢查更新（網址加 `?ver=1` 可強制查詢，測試用）。
- 部署到 GitHub Pages 時只需要 `index.html`、`css/`、`js/`（見 `.github/workflows/pages.yml`）；若新增執行期需要的頂層資料夾，記得同步更新該檔的 `cp` 清單。
- 模組之間的名稱與介面以 `docs/ARCHITECTURE.md` 為準，不要自行更改契約。
- 遊戲狀態需可序列化為 JSON，不可存放函式、class 實例、Map 或 Set。
- 若要調整畫面風格，請優先使用 `css/style.css` 內定義的顏色變數（`:root`）與共用類別，
  例如 `.btn`、`.panel-title`、`.card`、`.tab`、`.bar`，避免重複寫樣式。
