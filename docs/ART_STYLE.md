# 美術規範：「概念圖風格」（Concept style）

目標：整個遊戲（地圖場景、道具機器、人物、圖示、介面外框）統一成使用者提供的概念圖（`assets/art/source/concept_sheet.png`）的樣子。
範本：`assets/art/preview.png`（已去背素材）、概念圖原圖。人物與 5 件設備已使用圖集；其餘一律以程式依本規範重畫（**不可使用舊的像素風調色或做法**）。
舊畫面保留為「原像素風」（設定可切換，必須與改版前完全一致）；新風格只在 `artEnabled()` 為真時啟用。

## 2. 繪製規則
1. **1px 描邊**：每個精靈都有近黑藍描邊（`#14111b`），轉角圓潤，不要鋸齒毛邊；外輪廓描邊、內部分色不描邊（選擇性描邊）。
2. **三階明暗**：每個色相最多「暗/中/亮」3 階，光從左上來：亮面在頂與左、暗面在右與下。上緣再加 1px 高光（`#f6f6f6` 或該色最亮階）。不要抖色（dither）、不要噪點、不要漸層。
3. **扁平填色＋小細節**：大面積單色，細節用 1px 線（面板縫、螢幕圖樣、按鈕、把手）。設備螢幕用亮藍底＋白色心電圖/十字圖樣（如概念圖的 role.record/超音波機）。
4. **解析度**：與人物精靈同等級的細膩度：在縮放 1 時，1×1 格的設備約 28–40 px 寬，細節最小 1 px（螢幕像素，不是 2×2 放大的粗點）。先以 2× 內部解析度繪製再縮放，輸出給畫面時依 zoom×DPR 預縮放（同 `artdraw.js`）。
5. **等距視角**：與概念圖一致的 3/4 俯視（菱形 64×32 格），三面（頂、左、右）；頂面最亮、左面中、右面暗。
6. **室內地板**：米色菱形磚（`#eaded2`/`#ded2c6` 交錯、`#d2c6ba` 磚縫、淡淡接縫陰影），不是單色。牆：奶油色（`#ead2ae`→`#f6eaea`）＋白色踢腳線＋大窗（淺藍天色 `#cfe6f5`、窗框白）。
7. **陰影**：地面柔和橢圓陰影（`rgba(20,17,27,.18)`），不要硬黑影。
8. **戶外**：道路淺灰藍（`#8f98a4`→`#c9d0d8`）、白色斑馬線、人行道米色磚、草地明亮黃綠（`#5aae02`→`#9bd44a`），樹木圓潤、有高光、有描邊；建築物以奶油/淡粉/淺藍外牆、藍色玻璃窗。保持與概念圖「乾淨、明亮、醫療」的調性，不要暗沉。
9. **圖示**（狀態、金錢、點數、聲譽等）：圓角、描邊、明亮單色＋白色高光；概念圖的 6 個職能圖示（`role.*`）為風格基準。

## 3. 介面外框（DOM/CSS）
來自概念圖面板：
- **標題帶**：深海軍藍 `#1e365a`、白色粗體字、左側小十字/圖示、圓角 10px；分類用色帶（藍 `#1e365a`、綠 `#2a664e`、紫 `#5a5aa2`、青 `#1e7ea2`、橘 `#d9822b`、紅 `#c43e5a`）。
- **面板本體**：`#eaf6f6` 淺藍白、2px 海軍藍邊框、圓角 10px、柔和內陰影；卡片白底、1px `#c6d4e4` 邊、選取時藍色 2px 外框。
- **按鈕**：主要＝藍 `#2a7ef6`（下緣深一階 `#1e66ea` 3px 立體邊）、次要＝白底＋海軍藍邊、危險＝`#d24e66`、啟用中＝青綠。圓角 8px，按下時下沉 2px。
- **頂部列/分頁列**：海軍藍底、白字；數值晶片（資金/點數/聲譽）用圓角膠囊，圖示改用概念圖圖示（醫術＝`role.inquiry`、儀器＝`role.equip`、服務＝`role.educate`、紀錄/點值＝`role.record`、聲譽＝獎盃圖示（新畫）、資金＝金幣圖示（新畫））。
- 字體不變（Noto Sans TC 系統字），標題加粗；文字對比符合可讀性（淺底深字、深底白字）。

## 4. 驗收
- 新風格下地圖畫面「沒有任何一個元素看起來是舊畫風」：地板、牆、窗、門、招牌、建築、樹、路燈、汽車、所有 29 種道具、專區外框、狀態圖示、氣泡、進度條、選取圈。
- 手機（390×844 DPR3）與桌面 1280×720 皆清晰；縮放 0.4–2.5 不糊成一團。
- 切回「原像素風」＝改版前的畫面與介面（含舊 CSS 外觀），且無錯誤。
- 全部現有測試維持通過；效能 ≥ 55 fps（約 60 位角色）。
